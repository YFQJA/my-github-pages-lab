# AI Workshop

本项目是 `my-github-pages-lab` 中的 GitHub Pages 静态网页练习。AI Workshop 是一座个人 AI 工程实验台：通过四个虚构案例，展示如何设计知识检索、智能体、视觉理解和模型评估系统。案例不是可在线调用的服务。

## 在本地打开

将仓库中的文件放在同一目录，直接用浏览器打开 [`index.html`](./index.html)。不需要安装依赖、启动服务器或配置 API 密钥。

点击项目索引里的分类按钮可以筛选卡片，点击「全部」恢复。页面默认使用深色主题；右上角可切换主题，浏览器允许本地存储时会记住你的选择。系统启用「减少动态效果」时，页面会停用网格和过渡动画。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| [`index.html`](./index.html) | 页面结构、四张项目卡片和原创内联 SVG 图示 |
| [`style.css`](./style.css) | 深浅主题、响应式布局和动效 |
| [`app.js`](./app.js) | 分类筛选、结果计数和主题切换 |
| `README.md` | 本地运行和 GitHub Pages 说明 |

## GitHub Pages

`index.html` 位于仓库根目录，脚本和样式使用 `./app.js` 和 `./style.css` 等相对路径。在仓库所有者审核并配置 Pages 后，发布时可使用指定分支的根目录；页面支持项目名作为 URL 子路径，无需构建，也不需要后端。此代码不启用 Pages，也不改变仓库设置。

所有项目、流程和图示均为原创虚构示例。页面不请求外部资源或付费 API，不包含真实私人信息、账户凭据、密钥或客户资料。
